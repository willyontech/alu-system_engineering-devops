# SSH

This project introduces SSH (Secure Shell) and remote server authentication.

## Learning Objectives

- Understand what a server is.
- Understand SSH.
- Generate an RSA key pair.
- Connect to a remote server using SSH.
- Configure SSH client authentication.
- Understand the purpose of #!/usr/bin/env bash.

## Files

- 0-use_a_private_key: Connect to a server using an SSH private key.
- 1-create_ssh_key_pair: Generate a 4096-bit RSA key pair.
- 2-ssh_config: Configure the SSH client.
