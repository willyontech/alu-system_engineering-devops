# Web Server

This project introduces web server administration using Nginx.

## Tasks

- 0-transfer_file: Transfer files to a remote server using SCP.
- 1-install_nginx_web_server: Install and configure Nginx.
- 2-setup_a_domain_name: Configure a domain name.
- 3-redirection: Configure HTTP 301 redirection.
- 4-not_found_page_404: Configure a custom HTTP 404 page.
- 5-design_a_beautiful_404_page.html: Create a custom 404 design.

## Technologies

- Bash
- Nginx
- Ubuntu
- SSH
- DNS
- HTTP
