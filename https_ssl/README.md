# HTTPS SSL

This project covers HTTPS, SSL termination and HTTP redirection using HAProxy.

## Tasks

### 0. World Wide Web
A Bash script that displays DNS information about domain subdomains.

### 1. HAProxy SSL termination
Configure HAProxy to handle HTTPS traffic and forward requests to backend servers.

### 2. No loophole in your website traffic
Configure HAProxy to redirect HTTP traffic to HTTPS.
